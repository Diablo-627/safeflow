# safeflow
Студенческий проект по интеграции 1С+ ML - модуль на Python + PostgreSQL + SCADA
Полезные команды для работы:

# Посмотреть в какой ветке находитесь
git branch

# Переключиться между ветками
git checkout main
git checkout Danil

# Посмотреть разницу между ветками
git diff main..Danil

# Обновить ветку Danil с учетом изменений в main
git checkout Danil
git merge main
